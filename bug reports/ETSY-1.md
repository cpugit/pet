## Summary:
**The system does not display a warning when attempting to activate an empty coupon field.**

---

## Pre-conditions:					
1. The user is logged into the system.				
2. The page https://www.etsy.com/cart  is open in the browser.				
3. One or more items have been added to the cart.				

---
## Steps to reproduce:

1. Click the “Apply coupon code” button.				
2. Leave the coupon input field empty and click Apply.				

---

## Actual result:					
**The system did not display the message “The coupon code field cannot be empty.”**		

---			
					
## Expected result:					
**The system displayed the message “The coupon code field cannot be empty.”**
