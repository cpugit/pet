## QA Testing Project – Etsy (E-commerce Platform)

### Project Overview

**This repository contains a manual testing project for Etsy, a global e-commerce platform focused on handmade, vintage, and unique goods sold by independent creators.**

**The purpose of this project is to demonstrate practical QA skills by testing a real-world e-commerce web application and documenting the testing process according to industry standards.**

### Scope of Testing

The following core user flows were covered during testing:
* User registration and login   
* Product search and filtering
* Product page validation
* Add to cart functionality
* Checkout process
* User profile management
* Website navigation

### Testing Types

* Functional Testing
* UI Testing
* Smoke Testing
* Negative Testing

### Test Artifacts

The following QA documentation was created as part of this project:

* Test Cases
* Bug Reports
* Checklist
* Traceability Matrix

### Tools & Methodology

* Manual Testing
* Test design techniques (Equivalence Partitioning, Boundary Value Analysis)
* Defect prioritization (Severity / Priority)
* Structured test documentation approach

## Results

**During testing, defects of various severity levels were identified, including issues related to:**

* UI inconsistencies
* Business logic validation
* Form validation
* User flow interruptions

**This project demonstrates:**

* Understanding of SDLC and STLC
* Ability to create and maintain QA documentation
* Analytical thinking and attention to detail
* Structured approach to testing e-commerce platforms
